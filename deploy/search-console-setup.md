# Пошаговое подключение Google Search Console и Яндекс Вебмастера

## 1. Подтверждение прав на домен

### Вариант А: Через метатег в HTML (уже подготовлены слоты в `index.html`)
1. **Яндекс Вебмастер:**
   - Перейдите в [webmaster.yandex.ru](https://webmaster.yandex.ru) -> Добавить сайт: `https://focus-photocompany.ru`.
   - Выберите способ «Метатег».
   - Скопируйте код верификации (например: `a1b2c3d4e5f6g7h8`).
   - Вставьте в `index.html`:
     ```html
     <meta name="yandex-verification" content="a1b2c3d4e5f6g7h8">
     ```
   - Нажмите «Проверить» в Яндекс Вебмастере.

2. **Google Search Console:**
   - Перейдите в [search.google.com/search-console](https://search.google.com/search-console).
   - Выберите тип ресурса «Префикс URL»: `https://focus-photocompany.ru/`.
   - Выберите способ подтверждения «HTML-тег».
   - Скопируйте код верификации и вставьте в `index.html`:
     ```html
     <meta name="google-site-verification" content="ВАШ_КОД_ИЗ_GOOGLE">
     ```
   - Нажмите «Подтвердить».

### Вариант Б: Через DNS-запись в Cloudflare / Регистраторе (Рекомендуется для домена)
- Добавьте в DNS домена TXT-запись:
  - Имя: `@`
  - Значение: `google-site-verification=...` или `yandex-verification: ...`

## 2. Отправка карты сайта (Sitemap)

1. **В Google Search Console:**
   - Раздел **Файлы Sitemap (Sitemaps)** в левом меню.
   - В поле «Добавить новый файл Sitemap» введите:
     ```text
     sitemap.xml
     ```
   - Нажмите **Отправить**.
   - Статус должен стать «Успешно», тип: «Индекс Sitemap» (4 страницы + изображения).

2. **В Яндекс Вебмастере:**
   - Раздел **Индексирование** -> **Файлы Sitemap**.
   - Добавьте URL: `https://focus-photocompany.ru/sitemap.xml` и нажмите **Добавить**.

## 3. Настройка региональной привязки (Анапа, Краснодарский край)
1. **Яндекс Бизнес (бывший Справочник):**
   - Зарегистрируйте карточку компании «ФОКУС — Фотокомпания».
   - Адрес: Анапа, Пионерский проспект, 47.
   - Рубрика: «Фотостудия», «Фотоуслуги», «Видеосъёмка».
   - Укажите сайт: `https://focus-photocompany.ru/`.
   - Привяжите карточку Яндекс Бизнеса в Яндекс Вебмастере в разделе **Представление в поиске** -> **Региональность**.

2. **Переобход страниц (Быстроробот):**
   - В Яндекс Вебмастере: **Индексирование** -> **Переобход страниц** -> отправить `https://focus-photocompany.ru/`.
   - В Google Search Console: в строке поиска вверху ввести URL `https://focus-photocompany.ru/` -> нажать **Запросить индексирование**.
