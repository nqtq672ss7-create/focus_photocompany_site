# Руководство по максимальной безопасности и отказоустойчивости сайта «ФОКУС»

Данный документ содержит исчерпывающее руководство по защите сайта от сбоев, падений, взломов и DDoS-атак любого уровня (Layer 3, 4 и 7).

---

## 1. Архитектура эшелонированной защиты (Defense-in-Depth)

```
[ Пользователь / Атакующий ]
             │
             ▼
[ 1. Cloudflare Edge Network ]  <-- Фильтрация 99% DDoS (L3/L4/L7), WAF, Bot Fight Mode
             │ (Только доверенные IP Cloudflare)
             ▼
[ 2. Fail2ban + iptables/nftables ] <-- Автоматический бан на уровне ядра Linux при попытках сканирования
             │
             ▼
[ 3. Nginx Reverse Proxy (deploy/nginx.conf) ] <-- Лимит 15 req/s на IP, макс. 20 соединений, буферы, CSP
             │
             ▼
[ 4. Статические файлы + FocusShield Daemon ] <-- Защита от обхода путей, скрытых файлов, OOM-киллера
```

---

## 2. Подключение Cloudflare (Бесплатный уровень — 100% защита от крупных DDoS)

1. **Регистрация домена:**
   - Добавьте домен `focus-photo.ru` в бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com/).
   - Смените NS-серверы у вашего регистратора на выданные Cloudflare (например, `ns1.cloudflare.com`).

2. **Включение проксирования (Оранжевое облако):**
   - Для записей `A` (`@` и `www`) включите статус **Proxied** (оранжевое облако).
   - Теперь реальный IP вашего сервера скрыт от всего интернета. Все атаки принимает глобальная сеть Cloudflare (пропускная способность более 280 Тбит/с).

3. **Активация встроенных защит в панели Cloudflare:**
   - **Security → Settings → Security Level:** установите `Medium` (или `High`).
   - **Security → Bots:** включите **Bot Fight Mode** (автоматически блокирует спам-ботов и скраперы).
   - **Under Attack Mode:** при начале крупной DDoS-атаки включается в 1 клик — показывает интерактивный JavaScript-челлендж для всех подозрительных запросов, сайт продолжает работать без сбоев.

## 3. Развёртывание на сервере (Nginx + Docker)

### Вариант А: Запуск через Docker Compose (Рекомендуется)
```bash
cd /var/www/focus
docker compose -f deploy/docker-compose.yml up -d
```
- Контейнер автоматически перезапускается при любых сбоях (`restart: always`).
- Ограничены ресурсы RAM (1 ГБ) и CPU (2 ядра), что исключает падение хост-сервера по Out-Of-Memory.
- Файловая система смонтирована в режиме **Read-Only** (`:ro`), что делает невозможным внедрение вредоносных скриптов на диск.

### Вариант Б: Установка Nginx напрямую
```bash
sudo cp deploy/nginx.conf /etc/nginx/nginx.conf
sudo nginx -t && sudo systemctl reload nginx
sudo cp deploy/fail2ban-jail.local /etc/fail2ban/jail.local
sudo systemctl restart fail2ban
```

## 4. Встроенная защита в локальном сервере `serve.py` (FocusShield 2.0)

В сервер разработки `serve.py` уже интегрированы ключевые механизмы защиты:
- **Rate Limiting:** Скользящее окно — максимум 80 запросов в секунду на 1 IP. Превышение возвращает `HTTP 429 Too Many Requests`.
- **Concurrency Gate:** Ограничение максимум 64 одновременных рабочих потоков через семафор. Сервер никогда не исчерпает файловые дескрипторы ОС.
- **Anti-Slowloris:** Таймаут сокета 10 секунд — зависшие или медленные соединения мгновенно сбрасываются.
- **Path Traversal & Secret Shield:** Запрещён доступ к файлам `.git`, `.env`, `.py`, `.sh`, `.log`, `.db`, а также любым путям с `..`.
- **Security Headers:** CSP, X-Frame-Options: DENY, X-Content-Type-Options: nosniff, Referrer-Policy.
